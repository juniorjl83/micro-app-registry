# micro‑app‑registry

This repository hosts the **MVP** for a SaaS platform that aggregates modular micro‑apps. It contains:

- **frontend/** – a Nuxt 4 + Vue 3 + TypeScript single‑page application that provides the public catalog, registration flow, organization wizard, trial UI, checkout integration (Wompi), and an admin dashboard.
- **backend/** – a Kotlin + Spring Boot modular monolith exposing REST APIs for authentication, organization management, catalog, trials, billing, subscriptions, entitlements, audit logging, and admin operations.
- **docs/** – architecture diagrams, OpenAPI spec, and the implementation plan.

The project follows the implementation plan generated earlier and is ready for further development, CI/CD setup, and deployment.
